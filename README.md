## Project Overview

CampusAssist AI is a lightweight Agentic AI web application that helps students analyze campus-related issues and receive AI-assisted recommendations.

## Live Application

https://campus-support-ai.lovable.app/

## Agent Workflow

```text
Student Issue
     ↓
Triage Agent
     ↓
Action Agent
     ↓
AI Recommendation
```

## Agents

### Triage Agent
Classifies the issue, determines priority, provides reasoning and confidence.

### Action Agent
Recommends the appropriate campus department, next action and escalation status.
